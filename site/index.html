How it works

  1. 01
    Install

    Download Hopper for Apple silicon and install the native macOS app.

  2. 02
    Import

    Use the Docker CLI as usual — pull an image or use your existing Dockerfile and Compose files.

  3. 03
    Run

    Start your containers with familiar commands (e.g. docker run or docker compose up) and access them on localhost.

03

Docker Desktop transition / controlled procedure

3 modes

Change engines without changing how you work.

Coexist. Import. Replace.

  1. 01
    Coexist

    Install Hopper beside Docker Desktop and attach to its engine. Nothing moves until you choose.

    Lowest risk
  2. 02
    Import

    Choose any Docker-compatible engine, select its images, networks, and containers, then copy them into Hopper Engine.

    Guided move
  3. 03
    Replace

    Make Hopper Engine the active Docker context. Existing CLI and Compose commands continue to work.

    Full control
