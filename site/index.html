Everything, in one window

A full Docker toolbox
that feels native.

Containers, grouped by stack

Compose projects fold into collapsible stacks with an aggregate up/total badge and one-click start, stop, restart and remove for the whole group. Multi-select for bulk actions, rename, prune — the works.

Live everything

Streaming logs (demuxed stdout/stderr), CPU / mem / net meters, and a real interactive terminal via a hijacked socket.

Build · pull · push

Pull with per-layer progress, build from a Dockerfile with a live build log, and push using the credentials your docker login already set up.

One registry search

Docker Hub, GitHub Container Registry and Quay.io — searched together, ranked, one click from a pull.

Volumes & networks

Create, inspect, connect, disconnect and prune — with built-in networks protected from footguns.

Workspaces

Save named scopes by compose project or name pattern and filter the whole UI to just the stack you care about right now.

An MCP server in the box

Ship the same Docker tools to your AI client. List and control containers, stream logs, exec, manage images and volumes — all over the Model Context Protocol. Copy the launch config straight from Settings.

Compose

Whole stacks,
up and down.

Hopper reads the compose labels Docker already writes, so running stacks group themselves. Need to bring one up from a file? Point it at a compose.yml and watch the output stream live — driven by the real docker compose CLI, never a half-baked reimplementation.

  • Group, badge and act on running stacks instantly
  • Up / down from any compose file, with a project name
  • Streamed, line-by-line build & orchestration output
