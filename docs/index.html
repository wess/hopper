Hopper manages your containers and is the engine. On macOS it boots a real Linux VM in-process, runs dockerd inside it, forwards published ports to localhost, and shares your directories — so you can uninstall Docker Desktop entirely.

Be the engine

It carries its own ocean.

Hopper holds the virtualization entitlement itself, so the VM runs entirely in-process — no helper daemon, no second process to sign, supervise, or crash.

  1. Boots a Linux guest

    A raw arm64 kernel and Alpine initramfs on Apple's Virtualization.framework — up in about eight seconds.

  2. Runs dockerd inside

    Static Apache-2.0 Docker Engine, bridged out to ~/.hopper/run/docker.sock over vsock.

  3. Forwards ports to localhost

    docker run -p 8080:80 is reachable at http://localhost:8080 on your Mac — bound to loopback, not every interface.

  4. Shares your directories

    A bind mount outside $HOME reaches the container instead of resolving to an empty folder.
